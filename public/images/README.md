# Cómo cambiar las fotos del carrusel ("Nuestra estructura")

Todas siguen el mismo patrón: **`facility-01.jpg` hasta `facility-09.jpg`**.
Guarda el archivo con ese nombre exacto en esta carpeta (`public/images/`) y
la foto aparece sola en el sitio — no hace falta avisarme ni tocar código.

| Archivo | Espacio del carrusel |
|---|---|
| `facility-01.jpg` | 1ª foto |
| `facility-02.jpg` | 2ª foto |
| `facility-03.jpg` | 3ª foto |
| `facility-04.jpg` | 4ª foto |
| `facility-05.jpg` | 5ª foto |
| `facility-06.jpg` | 6ª foto |
| `facility-07.jpg` | 7ª foto |
| `facility-08.jpg` | 8ª foto |
| `facility-09.jpg` | 9ª foto |

Para **reemplazar** una foto, guarda el archivo nuevo con el mismo nombre
(por ejemplo, `facility-05.jpg`) y confirma "sustituir" cuando Windows
pregunte. Para **agregar una décima foto**, avísame — solo hay que sumar
una línea en el código para el espacio `facility-10.jpg`.

## Cómo llegar a esta carpeta en Windows

1. Abre el **Explorador de Archivos**.
2. En la barra de direcciones de arriba, pega esta ruta completa y presiona `Enter`:

   ```
   C:\Users\Usuario\Desktop\Landing Page\unicpo-miniimplantes\public\images
   ```

3. Arrastra tus fotos ahí adentro, o usa "Copiar" → "Pegar".
4. Haz clic derecho sobre el archivo → **Cambiar nombre** → escribe el nombre exacto de la tabla (con `.jpg` al final).

⚠️ **Cuidado con el doble ".jpg.jpg"**: si el archivo ya tiene extensión
`.jpg` visible y le escribes "facility-05.jpg" en el cambio de nombre,
Windows a veces guarda como `facility-05.jpg.jpg`. Si eso pasa, solo hay
que sacar el `.jpg` que sobra al final.

## Recomendación de tamaño

Cualquier foto de celular sirve. Si querés que cargue más rápido, lo ideal
es que cada foto pese menos de 1–2 MB — pero si mandas algo más pesado,
solo avísame que yo la comprimo por ti (ya lo hice con varias de las que
mandaste).
